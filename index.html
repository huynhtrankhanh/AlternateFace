Prove Theorems Without Fear

AlternateFace is a fast and gorgeous interactive theorem prover.

GitHub

Beautiful and usable interface

Current interactive theorem provers are made for researchers, not ordinary people. Similar to other theorem provers, AlternateFace also uses a solid logical foundation but the interface is simplified and carefully designed for normal people with no formal training.

Much faster

Unlike other theorem provers, AlternateFace is centralized. Most processing is done on powerful servers, not your own machine. This approach enables us to perform more optimizations than other theorem provers can do.

Open source

Trustworthy and reliable theorem provers such as Coq and Isabelle are open source. AlternateFace is open source too. You can read our source code to be sure of AlternateFace's correctness.
